# Syphon Filter 2 PC - Guest Runtime Alpha 9

This experimental Windows x64 build runs retail *Syphon Filter 2* gameplay
through the native PC runtime. It contains no game image or extracted retail
assets. Alpha 9 focuses on campaign correctness, native mouse control, scoped
weapons, and widescreen scene projection.

## Installation

1. Extract the complete ZIP into a new writable directory.
2. Keep every BIN track beside its corresponding CUE file.
3. Open PowerShell in the extracted directory.
4. Create the required empty developer marker:

   ```powershell
   New-Item -ItemType File -Path .\syphon_filter_cheats
   ```

5. Launch a standalone mission, replacing `N` and the example path:

   ```powershell
   .\syphon_filter.exe `
     --no-launcher --mission=N --scene-test `
     "D:\PS1\Syphon Filter 2 (USA) (Disc 1).cue"
   ```

Missions 1-8 use Disc 1; Missions 9-21 use Disc 2. To test connected campaign
progression, omit `--scene-test` and keep both disc dumps in one directory with
`Disc 1` and `Disc 2` in their CUE filenames. The graphical launcher still
targets Syphon Filter 1 and does not expose SF2.

## Changes since Alpha 8

- Native relative-mouse control now drives horizontal and vertical movement in
  both first-person aim and the enhanced third-person chase camera.
- First-person and chase-camera yaw/pitch sensitivity can be tuned separately
  with `--mouse-aim-yaw-sensitivity`, `--mouse-aim-pitch-sensitivity`,
  `--mouse-chase-yaw-sensitivity`, and `--mouse-chase-pitch-sensitivity`.
- Widescreen gameplay now widens the guest projection itself. World geometry,
  backgrounds, and NPCs remain visible at the edges instead of exposing empty
  strips or disappearing at the original 4:3 frustum.
- H11 and crossbow selection is restored, and the H11's line-based non-zoom
  optic now renders without affecting the silenced sniper rifle scope.
- Normal difficulty is restored for direct mission launches.
- Connected campaign flow no longer transfers Gabe's inventory and health to
  Lian at the Mission 1-to-2 handoff.
- Mission 1's post-C4 blocking CD wait now receives the hardware scheduling it
  needs to complete instead of exhausting the guest instruction budget.
- Missions 1-4 have passed interactive playtesting with the new widescreen and
  control paths; the complete 21-test Release suite remains the automated gate.

## Known issues

- Dying by falling during Mission 1's playable parachute opening restarts at an
  invalid boundary state: Gabe releases the parachute instead of replaying the
  complete in-engine intro and returning control while airborne.
- Missions 5-21 have not yet received the same interactive widescreen
  regression pass as Missions 1-4.
- Quick states are in-session only and do not persist after process exit.
- SF2 remains command-line only.
- Missions outside the interactively completed subset still need full human
  playthrough coverage despite deterministic route validation.

## Reporting issues

Include the mission number, approximate location, actions immediately before
the problem, last dialogue line, screenshots, and the log generated beside the
executable. Never upload BIN/CUE files or other copyrighted game data.
