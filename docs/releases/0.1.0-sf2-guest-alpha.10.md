# Syphon Filter 2 PC - Guest Runtime Alpha 10

This experimental Windows x64 build runs retail *Syphon Filter 2* gameplay
through the native PC runtime. It contains no game image or extracted retail
assets. Alpha 10 is the current end-to-end campaign playtest candidate, with
Missions 1-7 completed consecutively through the latest presentation, control,
audio and campaign paths.

## Installation

1. Extract the complete ZIP into a new writable directory.
2. Keep every BIN track beside its corresponding CUE file.
3. Open PowerShell in the extracted directory.
4. Create the required empty developer marker:

   ```powershell
   New-Item -ItemType File -Path .\syphon_filter_cheats
   ```

5. Launch a standalone mission, replacing `N` and the example path:

   ```powershell
   .\syphon_filter.exe `
     --no-launcher --mission=N --scene-test `
     "D:\PS1\Syphon Filter 2 (USA) (Disc 1).cue"
   ```

Missions 1-8 use Disc 1; Missions 9-21 use Disc 2. To test connected campaign
progression, omit `--scene-test` and keep both disc dumps in one directory with
`Disc 1` and `Disc 2` in their CUE filenames. The graphical launcher still
targets Syphon Filter 1 and does not expose SF2.

## Changes since Alpha 9

- Corrected briefing field parsing and layout for SF2's forward-order records.
- Scripted retail cameras now own vertical framing during in-engine cinematics;
  enhanced mouse pitch resumes automatically when gameplay control returns.
- Changed the default third-person mouse yaw sensitivity to 0.75. Independent
  aim/chase yaw and pitch command-line overrides remain available.
- Extended interactive native-wide campaign coverage through Missions 1-7.
- Retained full-width cinematic mattes, mouse aim, controller support, campaign
  saves, mission movies and automatic Disc 1-to-Disc 2 progression.

## Known issues

- Dying by falling during Mission 1's playable parachute opening can restart at
  an invalid boundary instead of replaying the full in-engine parachute intro.
- Mission-failure letterbox bars animate at the original 4:3 width, then extend
  across the widescreen viewport when the transition settles.
- The briefing screen's decorative frame artwork is not yet rendered.
- Mission 6 NVG presentation can leave a dark strip at the right edge.
- Quick states are in-session only and do not persist after process exit.
- SF2 remains command-line only, and Missions 8-21 still need equivalent full
  consecutive human playthrough coverage.

## Reporting issues

Include the mission number, approximate location, actions immediately before
the problem, last dialogue line, screenshots, and the log generated beside the
executable. Never upload BIN/CUE files or other copyrighted game data.
