# Syphon Filter 2 PC - Guest Runtime Alpha 3

This experimental Windows x64 build runs retail *Syphon Filter 2* gameplay
through the native PC runtime. It contains no game image or extracted retail
assets.

## Installation

1. Extract the complete ZIP into a new writable directory.
2. Keep every BIN track beside its corresponding CUE file.
3. Open PowerShell in the extracted directory.
4. Create the required empty developer marker:

   ```powershell
   New-Item -ItemType File -Path .\syphon_filter_cheats
   ```

5. Launch a mission, replacing `N` and the example path:

   ```powershell
   .\syphon_filter.exe `
     --no-launcher --mission=N --scene-test `
     "D:\PS1\Syphon Filter 2 (USA) (Disc 1).cue"
   ```

Missions 1-8 use Disc 1; missions 9-21 use Disc 2. The graphical launcher
still targets the SF1 product path and does not expose SF2.

## Alpha 3 improvements

- The captured retail HUD is authoritative by default, removing the doubled
  native/retail HUD seen in ordinary mission shortcuts.
- The minimap now preserves PS1 signed-coordinate and disabled-primitive
  behavior, eliminating the large radar wedge while retaining actor dots and
  threat cones.
- In-engine cinematic bars and black fades cover the complete adaptive
  widescreen output without stretching other UI.
- A Windows startup stack overflow in SPU reset is fixed.
- All 21 mission packages can be launched directly into their authored
  in-engine openings. Mission 3 remains the end-to-end completion reference.
- Dialogue, sound effects, controls, combat, weapons, objectives, retail HUD,
  death/checkpoint restart, and in-session F5/F9 quick states are functional.

## Known limitations

- Campaign progression and mission-to-mission transitions are not complete;
  launch missions individually.
- Music is absent, and missions other than Mission 3 have not been completed
  end to end in this runtime.
- Collision/room residency can still intermittently allow Gabe to fall
  through floor geometry.
- `P` reaches retail's pause/map input, but the transition is incomplete and
  can hide Gabe's model after closing. Avoid `P` in this build.
- A later Mission 3 dialogue can pause unevenly; `C` skips it.
- Quick states are in-session only and do not persist after process exit.

## Reporting issues

Include the mission number, approximate location, actions immediately before
the problem, last dialogue line, a screenshot for visual defects, and the log
generated beside the executable. Never upload BIN/CUE files or other
copyrighted game data.
