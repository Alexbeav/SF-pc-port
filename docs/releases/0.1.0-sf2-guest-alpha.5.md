# Syphon Filter 2 PC - Guest Runtime Alpha 5

This experimental Windows x64 build runs retail *Syphon Filter 2* gameplay
through the native PC runtime. It contains no game image or extracted retail
assets.

## Installation

1. Extract the complete ZIP into a new writable directory.
2. Keep every BIN track beside its corresponding CUE file.
3. Open PowerShell in the extracted directory.
4. Create the required empty developer marker:

   ```powershell
   New-Item -ItemType File -Path .\syphon_filter_cheats
   ```

5. Launch a standalone mission test, replacing `N` and the example path:

   ```powershell
   .\syphon_filter.exe `
     --no-launcher --mission=N --scene-test `
     "D:\PS1\Syphon Filter 2 (USA) (Disc 1).cue"
   ```

Missions 1-8 use Disc 1; missions 9-21 use Disc 2. The graphical launcher
still targets the SF1 product path and does not expose SF2.

For connected campaign progression, omit `--scene-test`. This example starts
at Mission 3 and continues through its save, ending movie, and Mission 4:

```powershell
.\syphon_filter.exe `
  --no-launcher --mission=3 `
  "D:\PS1\Syphon Filter 2 (USA) (Disc 1).cue"
```

Keep both CUE/BIN dumps in one directory with `Disc 1` and `Disc 2` in their
CUE filenames so the campaign can resolve the Mission 8-to-9 disc swap.

## Alpha 5 improvements

- Retail PS1 display-page persistence now drives world, HUD, text, radar, and
  pause/map composition without alternating frames, duplicated UI, or stale
  full-screen map overlays.
- HUD text, weapon artwork, minimap dots and threat cones, TARGET/DANGER bars,
  timers, notifications, and widescreen cinematic bars use the retail GPU
  packets and authored timing.
- Room-texture residency, collision-floor requests, and PS1-sized polygon
  validation remove the reproduced texture accumulation, floor loss, and
  angle-dependent vertex explosions.
- Gameplay audio uses a bounded generation-aware queue across host catch-up,
  death/restart, and F5/F9 instead of aborting on the former FIFO limit.
- P opens and closes the retail pause/map state while retaining the live
  mission. F5/F9 preserves both persistent display pages and active gameplay.
- Connected campaign progression carries the exact SF2 inventory and vitals,
  reaches the save handoff, selects ending movies, and resolves Disc 1/Disc 2
  mission sources automatically.
- Mission 1's opening, every retail-selected post-mission movie on both discs,
  Mission 21's `21_2`, and the final `Z17_1` stream are loaded from exact
  retail ranges. AIRBASE's `3_2`/`3_3` and AIRBASEX's `6_3` in-mission movies
  use the retail request and completion lifecycle with native STR presentation.
- All 21 missions pass 3,000-update quick-state and combat/restart routes on
  their correct discs. The 42-route matrix reports no collision gap, renderer
  repair, rejected ordering table, or rejected list merge.
- The complete Release suite passes 21/21, and SF1 retains its 29-movie,
  CD/DMA, and continuous-retail-loop gates.

## Candidate validation

- Mission 3 completion, save/load, Mission 4 opening-movie selection, and
  carried gameplay state have been exercised interactively.
- Mission 8 now completes through its ending movie, centered save prompt,
  automatic Disc 1-to-Disc 2 swap, Mission 9 opening movie, briefing,
  in-engine opening, and gameplay in the retail-authored order.
- Persisted slots display the correct SF2 destination names, and the non-linear
  Disc 2 runtime-resource order is translated independently from campaign,
  save and movie indices. The Mission 8-to-9 seam has been confirmed entering
  Pharcom Expo Center gameplay rather than the formerly misselected Moscow
  Club 32 resource.
- AIRBASE's authored mid-mission movie handoff has been exercised
  interactively and returns to the same live mission correctly.
- Still required: reach AIRBASEX's authored in-mission movie and confirm its
  downstream script reaction.

## Known limitations

- Mission 8 music cuts out shortly after gameplay begins, and occasional
  gameplay-audio timing or popping needs broader interactive coverage.
- Mission 1's in-engine parachute opening is prematurely skipped; other tested
  mission openings run normally.
- Mission 3 contains a delayed conversation which can eventually emit
  unrelated Mission 2 dialogue; skip it with C if progression stalls.
- Missions other than 3, 7 and 8 have not yet been completed end to end by a
  human tester in this runtime.
- Quick states are in-session only and do not persist after process exit.
- The SF2 path remains command-line only; the launcher still targets SF1.

## Reporting issues

Include the mission number, approximate location, actions immediately before
the problem, last dialogue line, screenshots for visual defects, and the log
generated beside the executable. Never upload BIN/CUE files or other
copyrighted game data.
