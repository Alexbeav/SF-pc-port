# Syphon Filter 2 PC - Guest Runtime Alpha 7

This experimental Windows x64 build runs retail *Syphon Filter 2* gameplay
through the native PC runtime. It contains no game image or extracted retail
assets.

Alpha 7 is the first public package of the current dialogue, checkpoint-audio,
controller, movie-flow and campaign-save work. It remains a playtesting build,
not a finished PC port.

## Installation

1. Extract the complete ZIP into a new writable directory.
2. Keep every BIN track beside its corresponding CUE file.
3. Open PowerShell in the extracted directory.
4. Create the required empty developer marker:

   ```powershell
   New-Item -ItemType File -Path .\syphon_filter_cheats
   ```

5. Launch a standalone mission, replacing `N` and the example path:

   ```powershell
   .\syphon_filter.exe `
     --no-launcher --mission=N --scene-test `
     "D:\PS1\Syphon Filter 2 (USA) (Disc 1).cue"
   ```

Missions 1-8 use Disc 1; Missions 9-21 use Disc 2. To test connected campaign
progression, omit `--scene-test` and keep both disc dumps in one directory with
`Disc 1` and `Disc 2` in their CUE filenames. The graphical launcher still
targets Syphon Filter 1 and does not expose SF2.

## Highlights

- Mission 1's complete parachute opening, speech and gameplay handoff work.
- Mission 3 dialogue selects the correct XA material and hands control back at
  authored points. Death/checkpoint reload resumes with synchronized effects.
- Mission 7 has been completed with continuous music and correct game logic.
- Xbox controller and keyboard/mouse input can be used simultaneously without
  the former crouch/back or roll/camera compound-input bugs.
- The retail HUD, radar, menus, map, weapon art, notifications and widescreen
  in-engine cinematic bars render through the guest GPU bridge.
- Connected ending movie, save prompt, next opening movie, briefing and mission
  transitions work, including the Disc 1-to-Disc 2 seam and sequel save names.
- All 21 missions boot directly. The full 42-route deterministic matrix passes,
  as do strict decoding of all 54 embedded STR streams across both discs.

## Important known issue

Mission 5 (McKenzie Airbase Exterior/AIRBASEX) is not currently a valid
playthrough target. In the observed connected run, guards were absent from the
opening and silenced-rifle areas, Homan and the truck remained stationary, and
UI flickering later escalated into full-screen flickering. This is an authored
mission-runtime bug in Alpha 7, not evidence of a bad disc dump. The natural
`6_3.STR` script transition therefore remains unverified.

Other limitations:

- Quick states are in-session only and do not persist after process exit.
- SF2 remains command-line only.
- Missions outside the interactively completed subset still need full human
  playthrough coverage despite deterministic route validation.

## Reporting issues

Include the mission number, approximate location, actions immediately before
the problem, last dialogue line, screenshots, and the log generated beside the
executable. Never upload BIN/CUE files or other copyrighted game data.
